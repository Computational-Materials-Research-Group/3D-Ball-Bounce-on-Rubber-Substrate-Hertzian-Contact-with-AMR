<p align="center">
  A dynamic finite element simulation of a <b>steel ball bouncing on a rubber substrate</b>
  using FreeFEM++. The ball is dropped from <b>50 cm</b> and undergoes repeated bouncing
  governed by Hertzian contact mechanics. A <b>coefficient of restitution of 0.70</b> models
  energy dissipation at each bounce. <b>Adaptive mesh refinement (AMR)</b> driven by the
  von Mises stress field automatically concentrates elements inside the contact patch.
  All fields are exported as <i>VTU/PVD files</i> for smooth ParaView animation across 500 frames.

## Physics

The simulation couples a rigid-body ball ODE with a quasi-static axisymmetric elasticity
solve for the rubber substrate at every time step. Key features include:

- Semi-implicit Euler integration of the ball's 1D equation of motion under gravity and Hertz contact force
- Hertz contact law: `F = K_hz · δ^(3/2)` where `K_hz = (4/3) · E* · √R`
- Coefficient of restitution (COR) applied at lift-off as an instantaneous velocity reversal
- Axisymmetric (r–z) FEM substrate solve using the cylindrical Lamé system with `1/r` terms
- P2 finite elements for displacements — avoids volumetric locking at ν = 0.45
- Two-way coupling: substrate surface deflection `uz_surf` feeds back into the contact kinematics
- AMR driven by von Mises stress with `hmin = a_contact / 12` inside the contact patch
- 3D output generated by revolving the r–z solution over 24 angular slices
- VTU/PVD export for ParaView with ball sphere geometry written alongside substrate mesh

## Simulation Strategy

### Ball ODE — Semi-Implicit Euler with COR

```
  v_{n+1} = v_n + dt · (−g + F_contact / m)
  z_{n+1} = z_n + dt · v_{n+1}

  δ_raw = R − (z_ball − Hz)        ← unclamped penetration
  F_contact = K_hz · max(0, δ_raw)^(3/2)

  Lift-off detected when δ_raw crosses 0⁺ → 0⁻:
    v ← +e · |v|                   ← velocity reversal with COR
    z ← Hz + R + 1 μm              ← push ball above surface
```

Three critical fixes implemented over naive Euler integration:

- **FIX A**: Use raw (unclamped) δ for lift-off detection. Clamped `max(0,δ)` stays at zero for multiple steps after contact ends, preventing COR from ever firing.
- **FIX B**: After COR, push ball 1 μm above surface to avoid re-entering contact on the very next step.
- **FIX C**: Sign convention — y=0 is bottom, y=Hz is top. Ball falls with v < 0; after bounce, v = +e·|v| (positive = upward).

### Substrate Solve — Axisymmetric Lamé System

At each time step the substrate equilibrium is solved quasi-statically under the current
Hertz pressure distribution on the top surface:

```
  p(r) = p₀ · √(1 − r²/a²)       ← Hertz contact pressure profile
  p₀ = 3F / (2π a²)               ← peak pressure
  a  = √(R·δ)                     ← contact patch radius
```

The cylindrical variational form is:

```
  ∫ r · [λ(∇·u)(∇·v) + 2μ ε(u):ε(v)] dr dz
  = ∫_Γ_top r · p(r) · v_z dr
```

with full hoop-strain terms `(ur/r)` included for axisymmetry.

### Two-Way Coupling

After the elastic solve, the axis-point surface deflection `uz(r=0, z=Hz)` is fed back
into the ball position to maintain consistency between substrate deformation and ball height.

## Mesh and AMR

### Initial Mesh

| Parameter | Value | Description |
|---|---|---|
| Radial divisions | Nr = 80 | Along bottom and top edges |
| Axial divisions | Nz = 35 | Along axis and outer wall |
| Element type | P2 | Quadratic triangular |
| Initial vertices | ~3 000 | Before first AMR pass |

### AMR Settings

| Setting | Value | Effect |
|---|---|---|
| err | 0.001 | Target interpolation error (tight) |
| hmin (in contact) | a / 12 | 12 elements across contact patch |
| hmin (free flight) | R / 30 | Adequate for stress field decay |
| hmin floor | 0.15 mm | Absolute minimum element size |
| hmax | R_sub / 8 | Coarsest allowed element |
| nbvx | 120 000 | Maximum vertex count |
| Refine on | SigmaVM (P0) | Von Mises stress-driven |

The mesh coarsens automatically during free flight (a → 0 between bounces) and refines
aggressively inside the contact patch when δ > 0, making the deformed substrate surface
clearly visible in ParaView.

### Critical AMR Rebinding Pattern

FreeFEM++ binds `fespace` to a mesh at declaration time. After `adaptmesh()` the mesh
connectivity changes, invalidating any previously declared DOF arrays. The correct pattern
used here is:

```
  1. Solve on current Th  →  ur[], uz[] filled
  2. Save: urSave = ur[];  uzSave = uz[]
  3. adaptmesh(Th, ...)   →  Th changes
  4. Declare NEW fespace on new Th
  5. Quasi-static: reset ur=0, uz=0 (no history needed)
  6. Persist DOF size: urDof.resize(Vhp2N.ndof)
```

Because the substrate problem is quasi-static (displacement is uniquely determined by
the current contact load), no history interpolation is required across mesh changes.

## Output Fields (ParaView)

### 3D Revolved Substrate (`sub3d_NNNN.vtu`)

| Field | Type | Description | Units |
|---|---|---|---|
| Disp_z_m | P1 nodal | Vertical displacement (indentation) | m |
| DispMag_m | P1 nodal | Displacement magnitude √(ur²+uz²) | m |
| SigmaVM_Pa | P0 cell | Von Mises stress | Pa |

Geometry is the r–z solution revolved over 24 angular slices (Ntheta = 24), producing
a full 3D substrate body with deformation baked into the node positions.

### Ball Sphere (`ball_NNNN.vtu`)

A triangulated sphere at the current ball centre position `zball`. Updated every saved
frame to show the ball in free flight or in contact. Mesh: 16 polar × 24 azimuthal quads.

### 2D AMR Cross-Section (`mesh2d_NNNN.vtu`)

| Field | Type | Description | Units |
|---|---|---|---|

| MeshSize_m | P0 cell | Element size (√area) | m |
| Disp_z_m | P1 nodal | Vertical displacement | m |

Use `Representation: Surface With Edges` and colour by `MeshSize_m` to see the AMR
refinement pattern evolving with the contact patch.

## How to Run

### Requirements

- FreeFEM++ v4.10 or later: https://freefem.org
- ParaView v5.x or later: https://www.paraview.org

### Step 1 — Run the simulation

```bash
FreeFem++ ball_bounce_amr.edp
```

The script will:
1. Build initial 2D axisymmetric mesh (Nr=80, Nz=35)
2. Initialise ball at z = Hz + hDrop with v = 0
3. For each of 10 500 time steps: advance ball ODE, solve substrate elasticity, apply AMR
4. Save output every 21 steps (≈ 500 frames total) as VTU + ball sphere + 2D mesh section
5. Write complete PVD collection files and CSV trajectory at the end

Console output example:
```
t=0.0ms z=500.00mm v=0.00m/s d=0.00mm uzS=0.000mm Fc=0.0N a=0.00mm sVM=0.00MPa nv=3041 [FREE]
t=4.2ms z=499.91mm v=-0.04m/s ...                                                        [FREE]
...
t=318.4ms z=0.03mm v=-3.13m/s d=0.15mm uzS=-0.089mm Fc=147.N a=1.93mm sVM=0.31MPa nv=8742 [CONTACT]
...
t=322.6ms z=0.01mm v=+2.19m/s d=0.00mm uzS=0.000mm Fc=0.0N a=0.00mm sVM=0.00MPa nv=3041 [FREE]
```

### Step 2 — Open in ParaView

1. `File > Open` → navigate to `D:\freefem++\ball_bounce_fine\`
2. Select `ball_bounce.pvd` → OK
3. Choose PVD Reader when prompted → OK
4. Click `Apply`
5. Set colour field to `SigmaVM_Pa`
6. Click `Rescale to Data Range Over All Timesteps` for consistent colour scale

### Step 3 — Visualise

**Option A — Von Mises stress evolution (recommended first view)**
```
Color by SigmaVM_Pa
Colormap: Rainbow / Plasma, range 0 to peak MPa
Press Play
→ Stress appears at first contact (~t = 318 ms)
→ Peak stress at r=0 directly under contact centre
→ Stress vanishes instantly at lift-off
→ Pattern repeats with decreasing peak at each bounce
```

**Option B — Substrate indentation**
```
Color by Disp_z_m
Colormap: Cool-Warm (diverging), centred at zero
→ Downward depression (blue/negative) under contact
→ Radial extent grows with contact patch radius a
→ Surface springs back to zero between bounces
```

**Option C — AMR mesh evolution (2D cross-section)**
```
Open mesh2d.pvd separately
Representation: Surface With Edges
Color by MeshSize_m
→ Uniform coarse mesh during free flight
→ Dense refinement in contact region at each impact
→ Mesh coarsens automatically between bounces
→ Each bounce shows fresh refinement cycle
```

**Option D — Ball trajectory post-processing**
```
Import ball_trajectory.csv into Python / Excel / ParaView SpreadSheet View
Plot zAbove_mm vs time_ms
→ Parabolic arcs between bounces
→ Geometric height decay: h_n = 500 · 0.49^n mm
→ Successive contact events visible as narrow dips to δ > 0
```

Press `Play` and set animation speed to **Slowest** for smooth contact event visualisation.

## What to Look for in Results

### Hertz Pressure Profile
During contact, the substrate top surface shows the characteristic semi-ellipsoidal
indentation profile of Hertz contact theory — maximum depression at r=0 tapering
smoothly to zero at r = a. The sub-surface stress bulb extends roughly one contact
radius below the surface.

### Bounce Height Decay
Plotting `zAbove_mm` vs `time_ms` from the CSV shows a clear geometric sequence of
parabolic arcs. The ratio of successive peak heights converges to e² = 0.49 as
predicted analytically for a constant COR model.

### Contact Patch Growth
During each impact, `a_mm` grows from zero to a maximum then returns to zero.
The maximum patch radius scales as `a_max ∝ F_max^(1/3) ∝ v_impact^(2/3)` — larger
impacts produce proportionally wider contact patches visible in the AMR mesh.

### AMR Refinement Pattern
The `Wireframe` view of `mesh2d.pvd` shows the mesh responding dynamically to the
contact: coarse during free flight, fine inside the contact patch during impact.
The stress gradient drives refinement into the sub-surface region where the maximum
shear stress occurs (approximately 0.48·p₀ at depth 0.48·a below the surface for Hertz).

## Common Errors and Fixes

| Error | Cause | Fix |
|---|---|---|
| `Out of bound P2KNIdE` | `fespace` declared globally, rebinding after `adaptmesh` | Declare all `fespace` inside the time loop after mesh changes |
| Ball stuck at surface | COR never fires because `max(0,δ)` stays at 0 | Use raw unclamped `δ_raw` for lift-off detection (FIX A) |
| Ball re-enters contact immediately after bounce | `zNew` still inside substrate | Push ball 1 μm above surface after COR (FIX B) |
| Ball falls through substrate | Sign error in COR velocity | After bounce set `v = +e·|v|` (positive = upward) (FIX C) |
| `umax = 1e+12` in substrate solve | Axis BC label wrong | Confirm label 4 is `x=0` line; add `on(4, ur=0)` |
| Simulation too slow | AMR every step at high `nbvx` | Reduce `nbvx` or apply AMR only when `delta > threshold` |
| No stress visible in ParaView | `SigmaVM_Pa` range too wide | Manually set range to `[0, peak_contact_MPa]` |
| PVD XML broken | PVD opened in write mode then appended | Use `ofstream(..., append)` for all entries after header |

## Extending the Model

| Extension | What to change |
|---|---|
| Viscoelastic substrate | Add Kelvin-Voigt dashpot: `σ += η · dε/dt` in variational form |
| Multiple bounces from different heights | Run several drop heights; overlay CSV trajectories |
| Non-spherical impactor | Replace Hertz `K_hz` with tabulated force-displacement from FEM sub-model |
| Oblique impact | Extend to 2D r–z with asymmetric load; rotate contact traction |
| Large-deformation rubber | Switch to Neo-Hookean hyperelastic formulation |
| Thermal effects | Add frictional heating term at contact interface |
| Different ball material | Recalculate `E*` via `1/E* = (1-ν_b²)/E_b + (1-ν_s²)/E_s` |
| Higher impact speed | Increase `hDrop`; check contact duration vs `dt` ratio (keep ≥ 10 steps/contact) |
| Finer mesh | Increase `nbvx` to 200 000 and reduce `hminAMR` floor |
